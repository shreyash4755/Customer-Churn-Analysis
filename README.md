📊 Customer Churn Analysis using Python

🎯 Goal
To identify key factors that influence customer churn and help businesses reduce customer loss.

🧰 Tools
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook

📊 Key Insights
- Month-to-month contracts have the highest churn.
- High monthly charges are linked to higher churn.
- Customers with longer tenure are more loyal.
- Offering online security and tech support reduces churn.

📁 Dataset
[Kaggle - Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
